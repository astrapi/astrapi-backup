Mount fehlgeschlagen

Das Archiv {{ archive }} konnte nicht gemountet werden.

Mögliche Ursachen:

  • FUSE nicht installiert: sudo apt install fuse3
  • Benutzer nicht in FUSE-Gruppe: sudo usermod -aG fuse backupadm
  • Falsche Passphrase für das Repository
  • Repository-Pfad nicht erreichbar
